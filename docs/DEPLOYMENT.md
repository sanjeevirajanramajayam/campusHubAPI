# 🚀 CampusHub Deployment Guide (Render.com)

This repository includes a production-ready **Render Blueprint (`render.yaml`)** that automatically provisions the API container, applies PostgreSQL migrations, and generates cryptographic JWT secrets in one click.

---

## 📋 Prerequisites
1. A free account at [render.com](https://render.com) (No credit card required).
2. Your CampusHub code pushed to a GitHub repository.

---

## ⚡ 1-Click Deployment Steps

### Step 1: Push Code to GitHub
If you haven't pushed your repository yet:
```bash
git remote add origin https://github.com/<your-username>/campushub-backend.git
git branch -M main
git push -u origin main
```

### Step 2: Open Render Blueprints
1. Go to [dashboard.render.com](https://dashboard.render.com).
2. Click **"New +"** (top right) and select **"Blueprint"**.
3. Connect your GitHub account and select your `campushub-backend` repository.

### Step 3: Review and Deploy
Render will automatically detect `render.yaml` and display:
* **Service 1**: `campushub-api` (Docker Web Service)
* **Service 2**: `campushub-db` (PostgreSQL Database)

Click **"Apply"**!

### Step 4: What Happens Automatically
1. Render provisions the PostgreSQL database.
2. Render runs `preDeployCommand: pnpm prisma migrate deploy`, applying all migrations to the cloud database.
3. Render builds our multi-stage `Dockerfile` (107 MB Alpine image).
4. Render exposes a public HTTPS URL:
   ```
   https://campushub-api.onrender.com/api/v1/health
   ```

## 🔒 Environment Variables Reference

| Variable | Description | Source |
|---|---|---|
| `NODE_ENV` | `production` | Set by `render.yaml` |
| `PORT` | `5000` | Set by `render.yaml` |
| `DATABASE_URL` | Cloud PostgreSQL connection string | Auto-linked by Render |
| `JWT_ACCESS_SECRET` | 256-bit cryptographically secure secret | Auto-generated by Render |
| `JWT_REFRESH_SECRET` | 256-bit cryptographically secure secret | Auto-generated by Render |
| `REDIS_HOST` | In-memory cache host | Cloud Redis / Upstash |
| `REDIS_PORT` | In-memory cache port | `6379` |
